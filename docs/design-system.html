04 / Motion and access

Immediate control highlight; expansion 160–240 ms; expressions 100–180 ms; chewing 350–500 ms per cycle. Motion is interruptible and never delays input. The actual native reducer drives expressions from real work state.

Reduced motion uses stable poses and short fades. Keyboard navigation, VoiceOver labels, normal text selection, contrast and a no-notch fallback are required.

Pause drawing when hidden. Never use animation alone to communicate recording or failure. No punishment expression when a request is declined.
