One companion, several runtimes.

Coucou is a desktop coordination surface for coding agents, expanded into chat, voice dictation, meeting notes and service integrations. Mobile apps reflect desktop state and return user decisions; the desktop remains the place where local agent requests are resolved.

SESSION DOMAIN

A pill is not a session.

PillCatalog gives a stable identity to a tool or service. PillSessionRegistry tracks the sessions behind it. SessionBoard decides which session is visible and can pop a waiting session into its own pill.

Urgency favors requests waiting for the user, then recent errors and finishes, then ongoing work. Selection has a hold interval to prevent rapid switching.

S10 S11 S15
REQUEST DOMAIN

Requests own a response channel.

ApprovalQueue holds at most five pending approvals. Entries bind request ID, session, agent, tool and input identity to an open socket. QuestionQueue separately tracks interactive questions.

The UI presents the queue head. Disconnects, matching completion events and timeouts remove individual requests.

04 / SYSTEM STUDY

Follow the work, end to end.

Six paths explain most of the system. Expand each one for the decision point, data movement and failure behavior.

A · Agent event → island update
Agent hook → nb-hook → Unix socket → HookServer → registry / board → AppState → island

HookServer reads newline-delimited JSON, separates status-line and question payloads, then routes ordinary events by agent tag and host application. UserPromptSubmit, tool activity, Stop and SessionEnd update session state; diff and recap logic consume relevant activity.

Ordinary events are acknowledged and the connection closes. The Mac socket is owner-only and checks peer UID. The listener defines a 1 MiB payload threshold, a receive timeout and a connection ceiling.

S05 S06 S10 S11
B · Permission request → exact user decision
PermissionRequest → ApprovalQueue → approval card → request-ID check → same socket → hook response

The socket stays open for an actionable request. A user click answers the request currently bound to that card; a supplied stale ID is ignored. Unsupported external-agent requests return “ask”. The non-App-Store path explicitly supports Codex, Copilot and Muse, and gates Hermes on settings plus a transport-capability flag.

Mac requests time out after 115 seconds, or 110 seconds for Copilot/Muse, without granting permission. On Windows/Linux, Rust requires an island acknowledgement within 800 ms before waiting for a decision, and caps the decision wait at 108 seconds. The frontend has its own 110-second cleanup timer.

S07 S08 S09 S34 S35
C · Chat with a provider or subscription CLI
Prompt + optional context → ClaudeService → provider API / local server / CLIRelay → response state

Chat is separate from observing a coding session. ClaudeService selects subscription-CLI routing when enabled, otherwise Anthropic or an OpenAI-compatible path. File/window context may be included, and the opt-in Mail mode can decorate a prompt with mail context.

API keys come through the native secret store. Cloud chat sends prompt/context to the selected provider; local chat targets the configured local model server. This is not an entirely offline product just because its session transport is local.

S16 S38
D · Dictation and meeting notes
Dictation key → audio / ASR → text transforms → optional AI cleanup → paste + history

FlowDictation finishes speech capture, applies dictionary/replacements, optionally calls cleanup or transformation, expands snippets, records history and inserts text into the active app. A missing Accessibility grant leaves text on the clipboard and prompts for access.

Meeting notes are a separate pipeline: microphone + system audio → Parakeet transcription → speaker/echo handling → persisted transcript → optional Claude or on-device Apple summary. Raw WAV files are removed after successful transcription; a failed transcription returns before that deletion, retaining audio for recovery.

The “OK Coucou” assistant has a separate VoiceEngine with wake detection, command capture and pause/recovery policies. It should not be conflated with hold-to-dictate.

S17 S18 S19 S20 S51
E · Mac ↔ iPhone
AppState → debounced CloudKit snapshots → PhoneLink → authenticated decision → CloudKit → ApprovalRelay → HookServer

SessionPublisher combines tasks, approvals and questions, removes duplicate snapshots and debounces publication by 500 ms. Project/session content is assigned to CloudKit encrypted fields; status, counts and request fingerprints are separate metadata.

ApprovalRelay hashes agent/session/tool/command/input identity, polls for matching decisions, checks age, and re-checks the current pending request immediately before answering. The iPhone uses device-owner authentication for Allow. Live Activities travel through a separate Worker → APNs path carrying an allowlisted status payload.

S23 S24 S25 S26 S27 S28 S30 S31
F · Windows/Linux ↔ Android
Tauri island snapshot → native phone-link hub → pinned TLS or encrypted relay → Android AppModel → authenticated decision

The desktop island owns the visible sessions and pending request, while Rust runs the paired link and applies phone decisions through the same local response mechanism. The LAN link offers port 47821, with another port chosen if needed. Android verifies the paired certificate fingerprint and reconnects with backoff.

Away-from-home mode adds a different Worker under android/relay. It requires an access key and room join proof, then forwards binary frames. Each room allows one live socket per role. If the peer is offline, the relay drops the frame and signals that state; it does not provide a store-and-forward inbox.

There is no single application database. Live state, preferences, secrets, history and mobile projections have different owners and retention rules.

08 / SYSTEM STUDY

What the architecture tells us.

These are maintainability observations and evidence limits, not claims from a full security or performance audit.

01

The local request lifecycle is the central contract.

Bounded queues, request identifiers, socket ownership, timeouts and matching remote fingerprints all protect the same invariant: a decision applies only to the request that is still waiting. Changes to hook payloads or session identity deserve cross-platform contract tests.

S08 S09 S25 S26 S34
02

Coordinator files concentrate several responsibilities.

HookServer.swift is 4,286 lines, IslandViewContent.swift 5,373, and IslandWindowController.swift 2,240. File size is not a defect by itself, but source inspection shows transport, routing, UI coordination and installation concerns meeting in large files. The existing pure queue and session types are useful boundaries for future extraction.

03

Parity is maintained through ports and protocols.

Apple clients share source, while Windows/Linux and Android carry separate implementations of state, rendering and behavior. The desktop hook handler explicitly identifies itself as a Mac port. Stable pill IDs and canonical event fields are more durable cross-platform seams than individual classes.

S01 S15 S35 S40
04

Documentation has observable drift.

The README says the Mac has zero third-party dependencies, but project.yml declares FluidAudio. It says Flow and Notetaker are Mac-only, while the Tauri startup and command registration wire both. The generic agent guide says third-party approval cards are not implemented, while HookServer has explicit Codex/Copilot/Muse paths and a conditional Hermes path. Source presence establishes implementation, not tested feature parity.

05

Availability and retention are feature-specific.

Phone decisions depend on the desktop still owning a pending request. The Android relay does not queue offline frames. Audio cleanup occurs after successful transcription. GitHub polling includes a five-minute stats timer, so “no work while hidden” should not be inferred across the entire app from the island animation policy.

 476          let path = Self.socketPath
 477          // sun_path on macOS is 104 bytes including the NUL terminator → max 103 usable bytes
 478          let maxSunPathBytes = MemoryLayout<sockaddr_un>.size - MemoryLayout<sa_family_t>.size - 1
 479          guard path.utf8.count <= maxSunPathBytes else {
 480              NSLog("HookServer: socket path too long (\(path.utf8.count) bytes, max \(maxSunPathBytes)): \(path)")
 481              return
 482          }
 483          try? FileManager.default.removeItem(atPath: path)
 484
 485          let fd = socket(AF_UNIX, SOCK_STREAM, 0)
 486          guard fd >= 0 else { return }
 487          serverFD = fd
 488
 489          var addr = sockaddr_un()
 490          addr.sun_family = sa_family_t(AF_UNIX)
 491          let cpath = Array(path.utf8CString)
 492          withUnsafeMutableBytes(of: &addr.sun_path) { raw in
 493              for (i, c) in cpath.enumerated() where i < raw.count { raw[i] = UInt8(bitPattern: c) }
 494          }
 495
 496          let bindRC = withUnsafePointer(to: &addr) { ptr in
 497              ptr.withMemoryRebound(to: sockaddr.self, capacity: 1) { Darwin.bind(fd, $0, socklen_t(MemoryLayout<sockaddr_un>.size)) }
 498          }
 499          guard bindRC == 0 else { close(fd); return }
 500          // Restrict socket to owner only
 501          chmod(path, 0o600)
 502          guard Darwin.listen(fd, 32) == 0 else { close(fd); return }
 503
 504          while true {
 505              let clientFD = Darwin.accept(fd, nil, nil)
 506              guard clientFD >= 0 else {
 507                  // Never end the server on a failed accept (#853); pause unless it was transient.
 508                  // A listening socket that is gone for good (closed, not a socket) ends the loop.
 509                  let err = errno
 510                  if err == EBADF || err == EINVAL || err == ENOTSOCK { break }
 511                  if err != EINTR && err != ECONNABORTED { usleep(100_000) }
 512                  continue
 513              }
 514              // Reject connections from other users (same-UID check)
 515              var euid: uid_t = 0
 516              var egid: gid_t = 0
 517              guard getpeereid(clientFD, &euid, &egid) == 0, euid == getuid() else {
 518                  close(clientFD)
 519                  continue
 520              }

 522              connectionLock.lock()
 523              let count = connectionCount
 524              if count < Self.maxConnections { connectionCount += 1 }

 526              guard count < Self.maxConnections else {
 527                  close(clientFD)
 528                  continue
 529              }

 531          }

  72      const att = attachmentOf(ws);

  81        return;
  82      }
