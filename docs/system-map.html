System map · 2 November 2026

Mochlet

A small companion for projects, agents and everyday knowledge.

A native macOS app that routes work through local coding agents, keeps durable project context and connects selected external sources. No mandatory server.

How the system fits together

Native surfaces

Notch / side companion · workspace · task board · attention requests · files · knowledge · meetings · settings. Character motion is separate from text layout.

Routing & orchestration

Registered project → exact root → task and profile snapshot → durable queue → run → exact agent session. One active coding run; meeting capture has an independent lifecycle.

↓
Execution adapters

AgentRuntime: Codex / Claude / Pi. ModelService: selected OpenRouter transcription and analysis profiles. AVFoundation + ScreenCaptureKit capture explicit audio; installed macOS voices provide optional replies.

↕
Durable local state

SQLite migrations and event history · exact session bindings · pending input · source revisions · delivery ledgers · portable knowledge documents · encrypted meeting segments with retention · Keychain credentials.

↕
Scoped connections

GitHub issues / discussions / Projects / PRs; Gmail / Calendar / Drive; Slack / Lark / Linear. Explicit account and project bindings. Refresh does not authorize coding, file moves or external messages.
